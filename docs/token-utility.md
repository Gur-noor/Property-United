## 1. Fee Discounts

Holding or staking $TRU reduces platform fees across all touchpoints:

| Fee type | Base rate | $TRU discount |
|---|---|---|
| Origination/Acquisition | 1–3% | Reduced for stakers |
| Secondary Transfer | 0.25–1% | Reduced for stakers |
| Asset Management | 1–2%/yr | Tier-based reduction |

Phase 1 SAFT investors automatically receive **0% origination fee** on their own property investments as a non-dilutive perk.

## 2. Priority Allocation

$TRU stakers get **first-allocation rights** on new property listings before they open to the general investor pool. High-demand properties often fill quickly — priority access is a material benefit.

## 3. Platform Access Tiers

Staking thresholds unlock access tiers with increasing benefits:

| Tier | Description |
|---|---|
| Standard | Base platform access |
| Silver | First-look on new listings, reduced fees |
| Gold | Priority allocation, deeper discounts, exclusive deals |
| Platinum | Institutional-style access, dedicated support |

## 4. Loyalty & Rewards

$TRU is earned by active platform participants:
- Property investment milestones
- Referrals that convert to verified investors
- Governance participation
- Long-term staking rewards

## 5. Governance

$TRU holders vote on platform parameters — see [Governance](./governance.md). This becomes active in Phase 5 when the DAO is established.

## 6. Buyback

A share of platform fees is used to buy back $TRU at governance direction, linking token value to platform revenue.

:::tip[The TRU Value Loop]
More properties → more fees → more buybacks + rewards → stronger $TRU → more investors attracted → more properties.
:::
